# 回忆地图与原片信息

作者：donglixiao

## 如何使用

1. 首页「回忆地图」浏览当前筛选的照片和视频。有 GPS 的原片自动落点。
2. 拖动、双指缩放，或使用右侧加减按钮；点封面聚合标记，底部列出这一组回忆。「展开这些地点」放大该组；同一坐标的照片保留为一组。
3. 在放映室展开「原片信息与下载」，查看设备、镜头、分辨率、格式、ISO、焦距、曝光、原始时间、视频时长和帧率；只展示原文件确实保留的字段。
4. 从单条回忆进入地图，默认只显示这一段。「显示附近回忆」显示地图范围内的其他带坐标素材。
5. 「待补位置」列出没有坐标的回忆；点编辑按钮，再点「地图选点」。点地图或「选择地图中心」，确认后回到编辑表单，最后保存。地点文字可独立填写，支持首页筛选。
6. 经纬度使用 **WGS84**。纬度 -90 至 90，经度 -180 至 180；不直接粘贴高德 GCJ-02 或百度 BD-09 坐标。清除坐标只影响回忆记录，重新扫描不会恢复已清除的位置。

支持电脑、手机触摸、键盘；地图容器获得焦点后方向键平移、加减号缩放，Tab 切换控件、Enter 打开回忆、Esc 返回。电视模式提供较大按钮，具体触摸／遥控器支持取决于浏览器。

## 无需 Key 的底图

Leaflet 1.9.4 提供交互，Natural Earth 公有领域大陆轮廓作本地概览。地图首次打开不请求外网；本地概览没有街道级细节。

「加载街道地图」使用 OpenStreetMap 标准公共瓦片，无需注册或 Key。图块请求包含当前地图区域和浏览器正常网络信息，不携带原片、文件名、故事或标签。查看区域会被底图服务获知；不会自动发送坐标作反向地理编码。关闭地图后下次仍从本地概览开始。

遵守 [OSM 瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)：署名始终可见，保留 Referer，使用正常浏览器缓存，不提供街道瓦片离线缓存、批量下载或预抓取。公共服务是尽力提供，网络受限地区可能无法加载；可切回本地概览。大规模公网部署应更换为自建或有容量保障的地图服务。本版尚未提供供应商切换、地名搜索、卫星图或自动地址解析。

如需 Apple 原版底图，需要在用户自己的开发者账户配置 [Maps Token](https://developer.apple.com/help/account/service-configurations/maps-tokens)。当前实现不依赖 Apple 账户，不包含他人的 Key。静态导出包含 Leaflet 和离线轮廓，地图与本地坐标编辑照常可用。

## 安装原片信息读取工具

从 [ExifTool 官方安装说明](https://exiftool.org/install.html) 下载；Windows 解压后将 `exiftool(-k).exe` 改为 `exiftool.exe`，必须保留同目录的 `exiftool_files`。Linux 可安装系统的 `libimage-exiftool-perl` 包。

在不入库的 `config.local.json` 中设置：

```json
{"exiftool": "C:/tools/exiftool/exiftool.exe"}
```

这是配置中的一个字段，请与已有 `media_root`、`ffmpeg` 等合并。重启服务后自动读取，也可运行 `python -m memoir scan`。未安装工具时可继续浏览与手动标注，只缺少自动提取。工具安装在素材电脑即可，手机和电视无需安装。

当前素材电脑已安装并校验 ExifTool 13.59 官方 Windows 包，位于 Git 忽略的 `.local/tools/`。迁移电脑时需要重新安装并调整路径。

提取只读，不调用 ExifTool 写入功能。缓存位于 `data/metadata/`，按素材大小、修改时间、路径 ID、工具路径、解析版本复用；不随 5 秒目录轮询反复解析大文件。拍摄日期采用 `DateTimeOriginal` 或 `CreationDate`，保留时间偏移；不把容器导出时间 `CreateDate` 或文件修改时间当作拍摄日期。扫描保留人工日期精度和人工位置。

静态发布的索引包含 GPS 和设备信息，发布范围应与家庭相册保持一致。编辑备份保存人工坐标；完整恢复原始信息需要保留原片并重新扫描。
