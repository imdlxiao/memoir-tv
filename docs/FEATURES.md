# 整理与重温

作者：donglixiao

## 批量整理

回忆流标题旁点击「批量整理」，点卡片上的选择按钮或「选择已显示」。可以先按年份、月份、地点、标签或关键词缩小范围，再选择需要整理的回忆。跨页选择保留，最多同时处理 200 条。

「编辑所选」中分别勾选需要修改的字段：

- 日期：具体一天、大约某月，或明确清除日期。
- 地点：统一填写，留空表示清除。
- 标签：默认追加并去重；也可明确替换全部标签或移除指定标签。
- 珍藏：统一加入或取消。

没勾选的字段不会改变，标题和故事不会被批量覆盖。每条最多 20 个标签，任何一条不通过校验或所选素材已移出时，整批不写入。本地服务写入前保存上一版元数据备份，纯静态模式一次写入浏览器记录。

## 接着上次看

视频看过 5 秒以上、距离结尾超过 5 秒时，会保存进度。再次打开自动恢复，并显示「从头看」。首页会出现「接着看」入口，未完成的视频卡片显示已看到的位置。播放完成后退出未完成列表。

进度每隔数秒、暂停、跳转、关闭时保存；最多保留 500 条，仅保存在当前浏览器。不同设备各自记录，不会在家庭故事 JSON 中加入观看行为。文件大小或修改时间改变时不会错误套用旧进度。清理浏览器站点数据会清除观看记录。

播放器支持 0.5×、0.75×、1×、1.25×、1.5×、2×，会记住上次倍速。「循环本段」仅影响当前视频；「连续播放」会在视频结束后继续下一条。

## 照片放映

照片可点击放大查看原始尺寸，再次点击适应屏幕。开启连续播放后，每张停留时间可选 5／8／15／30 秒。放大查看或切到其他标签页时暂停照片定时切换；关闭放映室后不再播放。电视模式默认开启连续放映。

每份素材都有「原片信息与下载」，可以查看原文件名、大小、拍摄时间、地点、标签和故事，并下载原片。下载原片不做压缩或转码。

## 往年今日与随机重温

「往年今日」分为两组：

- 往年今日：仅匹配以前年度、日期精确到天且月日相同的回忆。
- 往年这个月：仅匹配以前年度、日期只精确到月份且月份相同的回忆，明确标为“大约”。

未知日期和本年度素材不会被当作往年纪念日。没有匹配时显示空状态，不编造回忆。

「随便看看」从当前搜索和筛选后的结果中随机打开一条。例如先筛选某个地点、照片或珍藏，再随机重温。没有匹配结果会提示清除筛选。

## 浏览偏好

网格／列表、排序方向、播放倍速、照片间隔和连续播放开关保存在当前浏览器。拍摄月份可与年份、地点和标签叠加筛选，也适用于只精确到月份的回忆。
