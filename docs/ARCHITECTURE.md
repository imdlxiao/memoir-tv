# 架构与演进

作者：donglixiao

## 约束与选择

家庭原片总量远大于网页代码，不进入仓库，不复制到前端目录。静态索引和人工记录分离，扫描可以反复执行，人工标注不会被覆盖。采用 Python 标准库服务与原生 ES 模块，降低家庭电脑部署成本，以职责边界控制复杂度。

```text
原片目录 ──只读扫描──> catalog.json ──┐
                    thumbnails/     ├──> 合并后的回忆流
网页编辑 ──校验──> memories.json ────┘
                       │
                       └──> memories.backup.json / 手动导出
```

## 后端边界

`domain.py` 不依赖 HTTP、扫描器和存储，负责字段白名单、真实日期与精度。`storage.py` 将领域记录写入 JSON，进程内锁保护读取更新，临时文件与 `os.replace` 防止半写入。导入先完整校验再提交，避免半成功；写入前保存上一版备份。

`scanner.py` 只读素材，递归发现文件，跳过指向素材目录之外的链接。ID 来自相对路径散列，封面键包含 ID、大小和修改时间。日期只解析文件名的明确年月日，不以备份修改日期冒充拍摄时间。

`http.py` 负责静态文件、单段 Range、HEAD、请求大小限制和同源校验。原片通过索引 ID 访问并验证路径边界；仓库目录和本机配置不作为静态根目录暴露。

`__main__.py` 组合依赖。后台扫描单任务执行，失败保留现有索引。静态导出将合并数据发布为 JSON，前端复用同一组展示组件。

## 前端边界

| 模块 | 职责 |
| --- | --- |
| `api.js` | HTTP / 静态浏览器存储适配、备份校验 |
| `store.js` | 组合筛选、日期排序、计数 |
| `feed.js` | 回忆卡片、空状态、安全文本渲染 |
| `editor.js` | 日期精度、编辑表单、保存反馈 |
| `viewer.js` | 照片与视频放映、连续播放、资源释放 |
| `library.js` | 扫描进度、备份导入导出 |
| `tv.js` | 大屏模式、空间方向键导航 |
| `app.js` | 组装模块、事件协调、刷新视图 |

所有用户文本经过统一转义，媒体 URL 只允许 HTTP(S)。不加载第三方脚本、字体、图片或统计；插画、图标为原创 SVG。CSS 使用统一设计变量，浅色、深色和响应式布局分层。

## 当前边界

仓储适用于单进程家庭服务；进程锁不是分布式锁。记录更新采用最后一次字段写入生效，不提供协同编辑冲突界面。多进程部署、账号权限、审计、转码队列和跨设备实时推送属于后续阶段。

当前扫描不监听文件系统变化，新素材需手动刷新。移动或重命名素材会改变 ID，旧标注不会自动关联。原始格式解码由浏览器负责，不自动转码大型素材。

## 规模化路径

1. 实现相同仓储接口的 SQLite / PostgreSQL 版本，加入乐观锁与变更历史。
2. 扫描和转码拆为任务队列，支持 EXIF/容器拍摄时间、内容散列去重、重命名关联和代理视频。
3. 增加家庭空间权限，区分观看者、编辑者、管理员；对象存储使用授权地址。
4. 查询迁移到服务端分页与索引，保留展示与交互模块；需要时再迁移组件框架。
5. 增加多素材同条回忆、相册、人物标签、长故事和实时同步。自动识别保留来源和人工确认。
