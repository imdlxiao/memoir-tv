# 架构与演进

作者：donglixiao

## 约束与选择

家庭原片总量远大于网页代码，不进入仓库，不复制到前端目录。静态索引和人工记录分离，扫描可以反复执行，人工标注不会被覆盖。采用 Python 标准库服务与原生 ES 模块，降低家庭电脑部署成本，以职责边界控制复杂度。

```text
原片目录 ──只读扫描──> catalog.json ──┐
                    thumbnails/     ├──> 合并后的回忆流
网页编辑 ──校验──> memories.json ────┘
                       │
                       └──> memories.backup.json / 手动导出
```

## 后端边界

`domain.py` 不依赖 HTTP、扫描器和存储，负责字段白名单、真实日期与精度。`storage.py` 将领域记录写入 JSON，进程内锁保护读取更新，临时文件与 `os.replace` 防止半写入。导入先完整校验再提交，避免半成功；写入前保存上一版备份。

`scanner.py` 只读素材，递归发现文件，跳过指向素材目录之外的链接。ID 来自相对路径散列，封面键包含 ID、大小和修改时间。日期优先读取原片明确的拍摄字段，回退到文件名的年月日，不以备份修改日期冒充拍摄时间。

`metadata.py` 通过可选的本机 ExifTool 只读提取白名单字段。缓存键包含素材指纹、工具路径和解析版本；快速目录同步只读缓存，后台扫描才启动子进程。支持视频尾部的 QuickTime 元数据，不使用会提前停止读取的 `-fast2`。禁用外部 ExifTool 用户配置，Windows 路径通过 UTF-8 参数流传入。提取失败可重试，人工编辑仍通过仓储覆盖扫描字段，清空坐标使用显式 `null`。相机信息 `capture` 是只读事实，`coordinates` 是可编辑 WGS84 位置。

`library.py` 负责目录与索引同步。读取目录时只遍历文件属性，不读取视频内容、不等待封面解码；移出的素材立即从索引移除，人工记录独立保留。同路径移回可恢复标注。后台封面任务结束后重新核对目录，不发布任务开始时的旧快照，避免已移出的素材重新出现。目录不可用时保留原索引并返回明确错误。

`inventory.py` 缓存各目录的列表，通过目录修改时间发现成员变化，周期性核对原地覆盖。`storage.py` 依据索引／编辑文件指纹复用合并快照、ID 字典、序列化结果与 ETag；API 未变化返回 304。外部调用拿到深拷贝，静态导出修改路径不会污染服务端缓存。`identity.py` 保存受控迁移的路径映射；`migration.py` 单独负责计划与校验复制，不由普通扫描执行原片搬动。原片和 `data_root` 可以放在不同存储位置。

`http.py` 负责静态文件、单段 Range、HEAD、请求大小限制和同源校验。原片通过索引 ID 访问并验证路径边界；仓库目录和本机配置不作为静态根目录暴露。

`auth.py` 编排账号、会话、角色、逐条可见范围和审计；账号及设置校验仍位于 `domain.py`，持久化由 `storage.py` 的 `SecurityRepository` 承担。HTTP 层只提取 Cookie、适配状态码并调用授权服务。每个原片／封面请求均鉴权，目录按用户过滤后生成独立 ETag，授权后目录缓存在内存中最多 16 份／32 MiB。所有素材初始私密，首次发现时固定默认权限；账号和内容权限独立于扫描索引和编辑备份。

`__main__.py` 组合依赖。后台扫描单任务执行，失败保留现有索引。`exporter.py` 将合并数据发布为静态 JSON，只复制索引引用的封面，并阻止覆盖源码、记录或原片目录；前端复用同一组展示组件。

## 前端边界

| 模块 | 职责 |
| --- | --- |
| `api.js` | HTTP / 静态浏览器存储适配、备份校验 |
| `store.js` | 组合筛选、日期排序、计数 |
| `feed.js` | 回忆卡片、空状态、安全文本渲染 |
| `editor.js` | 日期精度、编辑表单、保存反馈 |
| `batch.js` | 显式多选、按字段批量整理，保存交给 API 适配 |
| `discovery.js` | 区分日期精度的往年发现、随机与未完成回忆入口 |
| `viewer.js` | 照片与视频放映、连续播放、资源释放 |
| `capture.js` | 原始设备、拍摄参数和位置入口，不猜测缺失字段 |
| `geo.js` | WGS84 校验与屏幕空间聚合，不产生网络请求 |
| `map.js` | 本地地图组件、缩略图图钉、选点、显式加载公共底图 |
| `progress.js` | 每浏览器进度、原片指纹验证、完成清理与数量上限 |
| `preferences.js` | 校验并持久化展示与播放偏好 |
| `library.js` | 扫描进度、备份导入导出 |
| `tv.js` | 大屏模式、空间方向键导航 |
| `sync.js` | 可见页面每 5 秒同步、切回页面同步，编辑和播放时暂缓 |
| `app.js` | 组装模块、事件协调、刷新视图 |
| `session.js` / `account.js` | 会话请求、失效检查、账号菜单和本人密码 |
| `login.js` | 登录、普通注册、一次性管理员初始化 |
| `admin.js` | 管理页面导航与加载协调 |
| `admin-users.js` | 创建账号、启停和密码重置 |
| `admin-visibility.js` | 单条内容可见范围与用户选择 |
| `admin-system.js` | 设置与分页日志 |

所有用户文本经过统一转义，媒体 URL 只允许 HTTP(S)。脚本、字体与插画不依赖运行时 CDN；Leaflet 与 Natural Earth 本地托管并保留许可。地图只有用户点击后才请求 OpenStreetMap 瓦片，不发起反向地理编码或图片上传。CSS 使用统一设计变量，浅色、深色和响应式布局分层。

批量写入在领域层校验字段，仓储层在同一锁内读取最新标注、按操作合并标签、验证整批结果，再原子提交一次。播放进度属于本机使用状态，不写入家庭元数据；播放资源销毁前先保存并解除事件监听，避免清空播放器时把进度覆盖为零。

## 当前边界

仓储适用于单进程家庭服务；进程锁不是分布式锁。记录更新采用最后一次字段写入生效，不提供协同编辑冲突界面。已有两级角色、逐素材权限、会话撤销及按日审计；多进程部署、多家庭空间、MFA、转码队列和跨设备实时推送属于后续阶段。

当前通过目录属性核对和页面轮询同步文件变化，不使用文件系统常驻监听。纯静态部署仍须重新扫描并发布。移动到目录内的新位置或重命名会改变 ID；原相对路径恢复后可关联保留标注。原始格式解码由浏览器负责，不自动转码大型素材。

## 规模化路径

1. 实现相同仓储接口的 SQLite / PostgreSQL 版本，加入乐观锁与变更历史。
2. 扫描和转码拆为任务队列，扩展现有 EXIF/QuickTime 读取，加入内容散列去重、重命名关联和代理视频。
3. 增加家庭空间权限，区分观看者、编辑者、管理员；对象存储使用授权地址。
4. 查询迁移到服务端分页与索引，保留展示与交互模块；需要时再迁移组件框架。
5. 增加多素材同条回忆、相册、人物标签、长故事和实时同步。自动识别保留来源和人工确认。
