# 用户、登录与内容可见范围

作者：donglixiao

## 第一次使用

1. 启动网站，未登录访问首页会进入登录页。
2. 在素材电脑打开 `data_root/security/setup-code.txt`，复制其中的一次性初始化码。服务器启动日志会显示这个文件的本机位置，不会输出码的内容。
3. 在登录页填写初始化码、自己的用户名和密码，创建唯一的超级管理员。密码至少 12 位、包含字母和数字，最多 128 位。初始化码使用后删除。

管理员只能通过这个本机初始化流程创建，最先注册的访客不会获得管理员权限。普通注册在管理员初始化完成后才开放；可在管理页关闭。不要把初始化码发给其他人。新安装的视频默认对全部已登录用户可见，照片默认仅管理员可见；管理员可以逐条调整。升级已有服务会保留原权限设置，不会自动公开私密内容。

登录后点首页右上角账号名称 →「用户、可见权限与系统管理」。手机使用同一入口，普通用户也可通过底部「账号」打开自己的账号菜单。

## 两种角色

| 操作 | 超级管理员 | 普通用户 |
| --- | --- | --- |
| 浏览与播放 | 所有回忆 | 仅开放给自己的回忆 |
| 编辑日期、故事、地点、标签和家庭珍藏 | 可以 | 不可以 |
| 扫描、编辑记录备份与恢复 | 可以 | 不可以 |
| 创建、启停账号与重置密码 | 可以，作用于普通账号 | 不可以 |
| 配置单条素材可见范围 | 可以 | 不可以 |
| 日志与基础设置 | 可以 | 不可以 |
| 修改本人密码、退出本人会话 | 可以 | 可以 |

账号角色固定为两级；普通注册和管理员创建账号都只能生成普通用户，接口也不允许传入 `admin` 提权。最高权限账号不能被网页停用、降级或通过普通账号重置入口修改；本人可在账号菜单验证旧密码后修改密码。

管理员忘记密码时，在素材电脑**先停止网站服务**，运行 `python -m memoir reset-admin`，在不回显的终端提示中输入新密码两次，然后重新启动服务。这个本机恢复入口没有网络 API，也不会输出密码。不要在服务运行时同时修改同一账号文件。

## 内容范围

「内容可见范围」展示所有照片和视频，支持搜索、范围筛选、分批显示，每条可选择：

- **全部用户可见**：所有已登录且未停用的账号可见，匿名访客仍不可见。
- **仅超级管理员可见**：普通账号的列表、地图、筛选统计和原片入口都不包含它。
- **指定用户可见**：勾选普通账号；超级管理员始终可见。

权限独立存储，以素材稳定 ID 关联。扫描和人工编辑不会覆盖权限；受控迁移保留 ID 时也保留权限。新视频默认全部用户可见，新照片默认仅管理员可见；基础设置可以分别调整两种类型的新素材默认范围。已发现素材不会因此批量改变。

每次请求目录、原片、HEAD、Range 和封面都进行后端鉴权，不依赖前端隐藏按钮。撤回权限后，后续请求立即拒绝；传输中的媒体流约每秒检查一次权限。页面额外每 5 秒检查登录和权限变化，播放或编辑弹窗不会暂停这个安全检查。已发送到设备、缓冲或下载的内容无法远程收回。

## 记住登录

服务器生成随机 256 位不透明凭证，浏览器通过 `HttpOnly; SameSite=Strict; Path=/` 持久 Cookie 保存；网页 JavaScript 和 localStorage 不保存登录凭证。服务端仅保存凭证的 SHA-256 摘要，篡改后不能找到有效会话。默认有效 30 天，管理员可为新登录设置 1–90 天，每个账号最多保留 20 个会话。

重新打开浏览器、重启网站服务均可沿用未过期凭证。清除**站点 Cookie / 网站数据**会失去登录，单独清除图片缓存不等于清除 Cookie。退出登录撤销当前会话；停用账号、重置密码或修改本人密码撤销该账号所有会话，重新启用也不会恢复旧凭证。

建议一直用固定入口收藏。`127.0.0.1`、IP 和 `电脑名.local` 是不同主机，各自保存 Cookie，换入口时可能需要重新登录。

## 安全与部署边界

- 密码采用随机盐与 PBKDF2-HMAC-SHA256（600,000 次）单向哈希；不保存明文或可逆加密密码。登录错误不区分不存在、密码错误与停用。每来源 IP 的认证请求 15 分钟最多 20 次；注册、初始化和修改密码也计入限制。该内存限流重启会重置。
- 修改请求必须是 JSON，同源 Origin 校验与 SameSite Cookie 共同限制跨站请求；账号与权限在服务端决定，忽略前端宣称的角色。
- 私密目录响应按用户生成 ETag，原片、目录、封面和页面使用 `no-store`；新版封面 URL 增加访问版本以绕开旧版长期缓存。升级前已缓存或下载的内容不可能通过新权限抹去。
- 当前局域网地址仍是 **HTTP**，密码和 Cookie 的网络传输并未加密。只用于可信家庭网络。需要 HTTPS 时应使用可信 TLS 反向代理，并在 `config.local.json` 设置 `"secure_cookies": true`；不要在 HTTP 环境开启，否则浏览器不会发送登录 Cookie。服务不信任客户端传入的 `X-Forwarded-Proto`。
- 保持单服务进程访问同一数据目录；JSON 锁不是跨进程锁。当前没有 MFA、短信验证、邮件找回、分布式限流或公网攻防认证。手机号仅为可选联系资料，不作为身份核验。

实现参考：[OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。

## 数据、日志和备份

`data_root/security/accounts.json` 保存账号、会话摘要、权限及设置；`security/audit/YYYY-MM-DD.jsonl` 按 UTC 日期追加登录、账号、内容访问和管理操作日志。日志页按日期浏览、每页最多 100 条，读取单页最多 64 KB。同一用户、IP 和原片一分钟内的分段请求合并成一次访问，HEAD 和封面请求不计为原片观看；浏览器预载原片也属于访问，不代表完整看完。

整机备份应包含 `security/`，并按私密文件保管。网页的「编辑记录备份」只备份回忆标注，不包含账号和权限；恢复这个备份不会改变可见范围。家庭账号、会话、手机号、日志和初始化码均不能提交 Git。旧的有效会话摘要随整机备份恢复后可能仍有效，恢复应在可信机器进行。

纯静态站点无法执行登录与后端权限校验。启用账号后，默认拒绝静态导出；确实需要无登录保护的公开副本时显式使用 `python -m memoir export --public ...`，只导出“全部用户可见”的素材，且目标必须是空目录。指定用户或仅管理员内容不会进入副本。公开副本脱离登录保护，外部媒体服务器也须单独限制它提供的原片范围，不能将整个家庭原片目录公开映射。
